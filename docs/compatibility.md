# Compatibility and Known Limitations

Updated: 2026-11-04. This page records the limits of the current support claims; it does not repeat the development log.
Scope follows the [capability matrix](obconnector-dotnet-progress.md); verdicts follow the [acceptance criteria](acceptance-criteria.md).
Accepted combinations, the environment in which they were observed, and the failures that remain open are listed in the tables below.
The recorded evidence was not re-run for this documentation pass, and no existing failure was closed by it.

## Current server assumptions and development freeze

Local User Secrets currently contain only the two direct profiles `mysql-direct` and `oracle-direct`, targeting
OceanBase 4.4.2.2; both explicitly set `TLS Mode=Disabled`. There is no proxy/ODP, multi-node/OCP/TNS,
OB20/trace, or non-native authentication/KDC profile. The read-only handshake special passed 4/4, and the two OB20 specials were skipped because there is no
`ob20` profile; this proves the current configuration state, not that the server will never support these capabilities.

Therefore development and fixes for the following items are frozen until the corresponding real server endpoints, versions, and positive/negative acceptance data are provided:

| Item | Current evidence | Development decision |
| --- | --- | --- |
| TLS/mTLS/enterprise CA/revocation/rotation | Both real profiles are TLS Disabled and there is no certificate endpoint | Not developed for now; the TLS API, negative cases, and the Deferred marker are retained |
| OB20/trace/compressed OB20 | No OB20 profile; historically forced OB20 failed because the server returned `Layer=mysql` | Not developed for now; ordinary protocol fallback and the rejection boundary are retained |
| OBProxy/ODP/multi-node/OCP/TNS/backend migration | No real proxy or discovery-service profile; the local relay verifies client routing only | Not developed for now; local topology fixtures are not upgraded to HA conclusions |
| Non-native authentication, KDC, credential rotation | Currently only native account direct connections; no plugin/KDC endpoint is provided | Not developed for now; the existence of the Java SPI does not count as an OceanBase deployment capability |
| Additional character sets | D-07e added CP850/HP8/MacRoman and SWE7 results; D-07f/g/h added strict CP932/UJIS/EUCJPMS mappings and the specified success subsets | Only per-item evidenced success subsets are closed; the Java-matched failures of ordinary Oracle SJIS/Big5/EUCKR/CP932/UJIS/EUCJPMS are retained, and other deployments stay frozen |

## Unclosed failures and assumptions

| Mode/item | Historical conclusion | Handling boundary |
| --- | --- | --- |
| Oracle SJIS/Big5 initialization | Independently reproduced with Java as 900 | The failure is retained and not written up as all character sets being usable |
| Oracle nested-table column | Java reproduces 600/0A000; type creation/PL use cannot substitute for column storage | Distinguish type definition from persistent-column capability |
| Oracle SELECT CURSOR column | prepared902/HY000 also reproduced with Java; the text value shape does not match four-byte parsing | Column metadata or PL OUT success is not treated as passing value decoding |
| Oracle VIEW/SYNONYM | CREATE returns 1031/HY000 | Insufficient privileges; it does not mean OceanBase has no views/synonyms |
| Oracle binary named TZ | Non-empty region name returns 1882, and Java server-prepare also fails | A numeric offset/text pass cannot substitute for a binary region name |
| Oracle long NUL script | A 12003-character multi-statement passes; a larger double SELECT times out in .NET/Java | Length and path limits are retained; a timeout may occur after sending |
| MySQL TIME extreme fractional seconds | Storage of ±838:59:59.999999 truncates to whole seconds; strict text returns 1292 while binary still truncates and succeeds | No promise that both paths convert identically, and no silent client-side truncation |
| MySQL zero date | Fails under the current SQL_MODE precondition; no table was created | A profile existing does not mean zero-date storage is accepted |
| Native prepare1295 | Verified against actual storage after injecting a rejection through the relay | Proves only the client fallback branch; the tenant's native 1295 was not reproduced |
| ChangeDatabase/special endpoints | Missing configurations such as alternateDatabase, a dedicated unsupported auth/disabled-autocommit endpoint, and real OB20/trace | The configuration skips stay open and cannot be counted as passed |

The 2026-10-28 all-direct recheck snapshot is **625 passed, 12 failed, 6 configuration skips, 643 items in total**;
this is the result for that run's selection and code, not the current project test total or a current overall pass claim.
Later single-module successes cannot automatically close all 12 failures, and the 6 items from before the UTF8MB3 fix are no longer listed as current defects.
The historical SecurityTests suite of 671 items was not fully executed in that run, only the special 11/11; this is not a current security-suite pass count.
